# aif-ext-grilling

Расширение AI Factory, которое по параметру `--grilling` дополняет `aif-explore`
проверкой решений через вопросы по методу `grilling` Matt Pocock.
Без параметра действует стандартный скилл.

Расширение добавляет один блок инструкций штатным механизмом `injections`
после заголовка YAML, перед основными инструкциями (`prepend`).
Базовый скилл, его справочные материалы, конфигурация и форматы исследовательских
документов остаются под управлением AI Factory. Отдельный `grilling` не требуется.
Исполняемого кода, дополнительных зависимостей и настроек MCP нет.

## Установка

Нужны установленный AI Factory, инициализированный проект и выбранный в нём
`aif-explore`. Совместимость проверена с AI Factory 2.20.0.

Выполните команду установки из корня проекта, где находится `.ai-factory.json`.

```bash
ai-factory extension add https://github.com/kozlovaa1/aif-ext-grilling.git
```

Для установки из локального каталога укажите путь к нему.

```powershell
ai-factory extension add "C:\путь\к\aif-ext-grilling"
```

Укажите каталог с `extension.json`. В Linux и macOS используйте соответствующий
абсолютный путь. Сохраните локальный каталог на месте для последующих обновлений.

Если AI Factory ещё не настроен в проекте, сначала выполните `ai-factory init`,
выберите нужную среду, например Codex app, и включите `aif-explore`.
После установки начните новый разговор, чтобы агент прочитал обновлённый скилл.

## Использование

Обычное исследование в Codex:

```text
$aif-explore Хотим изменить повторную отправку заявок. Помоги уточнить поведение.
```

Исследование с прожаркой:

```text
$aif-explore --grilling Хотим изменить повторную отправку заявок.
```

Параметр можно сочетать со штатным режимом, например:

```text
$aif-explore --grilling ultra Хотим изменить повторную отправку заявок.
$aif-explore regular --grilling Хотим изменить повторную отправку заявок.
```

`--grilling` распознаётся только как отдельный токен в начальной группе перед
темой, рядом с необязательным `regular`/`ultra`. Упоминание флага внутри темы
или в кавычках не включает прожарку. Распознанный флаг убирается перед штатным
разбором режима и темы. Например, `--grilling ultra отправка` передаётся основному
скиллу как `ultra отправка`.

В средах с командами через косую черту используйте `/aif-explore --grilling`.
Это параметр инструкций скилла для модели, а не команда CLI AI Factory.

При включённой прожарке агент сначала изучает доступные факты, затем разбирает
существенные решения раундами до трёх независимых вопросов. У каждого вопроса есть рекомендуемый
ответ, причина и компромисс. Зависимые вопросы переходят в следующий раунд.
Ответы можно изменить; пропущенный вопрос не означает согласие с рекомендацией.

Можно попросить «задавай по одному вопросу», «пропусти это» или «достаточно».
Запрос «продолжим без гриллинга» возвращает обычное свободное исследование.
Обычные ответы продолжают текущее интервью без повторения флага. Новый явный
вызов `$aif-explore` без `--grilling` возвращает стандартный скилл. Чистый поиск
фактов не превращается в обязательное интервью даже с флагом.

## Сохранение результатов

Действуют штатные правила `aif-explore`:

- `regular`: запись после выбора сохранить или явной просьбы пользователя;
- `ultra`: запись в выбранный исследовательский набор по правилам этого режима;
- путь определяется `paths.research` и остальной конфигурацией AI Factory;
- язык вопросов и документов определяется `language.ui` и `language.artifacts`.

Параметр `--grilling` не переключает режим сохранения и не создаёт собственный журнал.
В сводке разделяются согласованные решения, факты, предположения и отложенные
вопросы с рисками. Служебные заголовки и маркеры AI Factory сохраняются.

Для передачи результата в планирование можно написать:

```text
Сохрани согласованные решения и открытые вопросы в исследовательский файл.
Затем перейди к $aif-plan и используй этот файл как источник.
```

В `ultra` следует передать точный путь к `RESEARCH.md` выбранного набора.
Без сохранения результаты остаются в текущем разговоре; новый разговор их
автоматически не получает. Подтверждение сводки не запускает реализацию.

## Обновление и удаление

Из корня целевого проекта:

```powershell
ai-factory extension list
ai-factory extension update aif-ext-grilling --force
ai-factory extension remove aif-ext-grilling
```

В версии 1.1.0 прожарка стала включаться только параметром. После замены локального
источника версии 1.0.0 обновите расширение и начните новый разговор: старые
инструкции могли остаться в контексте предыдущего. Если каталог источника
изменился, выполните `extension add` с новым путём вместо обновления старого.

Повторное применение не должно дублировать вставку. При `ai-factory update`
AI Factory заново применяет зарегистрированные вставки после обновления базовых
скиллов. Удаление расширения снимает его блок инструкций.

## Источники и отличия

Метод адаптирован из [grilling Matt Pocock](https://github.com/mattpocock/skills/blob/7739eaed7f8f3915437a8def198a6d0d7206dbc7/skills/productivity/grilling/SKILL.md),
ревизия `7739eaed7f8f3915437a8def198a6d0d7206dbc7` от 29 октября 2026 года,
лицензия MIT. Уведомление об авторских правах приведено в [LICENSE](LICENSE).

Сохранены дерево зависимых решений, раунды, рекомендации и самостоятельный
поиск фактов. Для `aif-explore` адаптированы:

- ограничение до трёх вопросов за раунд вместо всей доступной границы дерева;
- завершение при достаточности решений для следующего шага;
- штатное сохранение AI Factory вместо отдельного журнала;
- работа с доступными инструментами без обязательных `Skill` и подагентов;
- явное различение рекомендаций, ответов, пропусков и разрешений на действия.
- включение только через `--grilling`, со стандартным поведением без флага.

## Выполненная проверка

На AI Factory 2.20.0, ревизия `e7a27083eb619c1dc930f406e3de30aa65f108e5`,
для версии 1.1.0 проверены схема манифеста и цикл CLI в отдельном проекте:
установка версии 1.0.0, обновление до 1.1.0 с удалением старой вставки `append`
и добавлением единственной вставки `prepend`, повторная установка без
дублирования, принудительное обновление базовых скиллов и удаление с
восстановлением исходного содержимого. Проверка охватила общий каталог Codex CLI/Codex app
и отдельный каталог Claude. Реальный диалог с моделью отдельно не проверялся.

Формат расширения: [документация AI Factory](https://github.com/lee-to/ai-factory/blob/2.x/docs/extensions.md).
Это набор инструкций для модели: качество самого диалога зависит от модели
и контекста. Проверка установки не доказывает, что агент всегда соблюдает метод.
